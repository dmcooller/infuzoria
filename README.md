# Infuzoria

Infuzoria is an application that helps to work with images taken under a microscope. It allows to measure the size of objects on the image by drawing a line on the image and setting the FOV (field of view) value.

The application is written in Python using the PySide6 library for the graphical user interface and the OpenCV library for image processing.

## Installation

### From source

To install the application, you need to have Python 3.11 or 3.12 installed on your computer. You can download Python from the official website: https://www.python.org/downloads/
